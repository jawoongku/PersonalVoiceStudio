# 제품 명세서

## 제품명(가칭)

Personal Voice Studio for macOS

## 목표

사용자가 문장을 보고 자신의 목소리를 직접 녹음하면, 앱이 음성 품질과 발화 일치 여부를 검사하고 학습 가능한 데이터만 모아 개인 Voice Package를 만든다. 사용자는 이후 텍스트를 입력해 자신의 목소리로 WAV를 생성한다.

## 핵심 사용자 흐름

1. Voice 프로젝트 생성
2. 앱이 권장 문장 제시
3. 사용자가 macOS 마이크로 녹음
4. 자동 품질·발음 검사
5. 사용 가능/재녹음/제외 판정
6. 데이터가 충분해지면 학습 시작
7. 학습 진행률·loss 확인
8. Voice Package 생성
9. 텍스트 입력 및 TTS 생성
10. 재생·저장·히스토리 관리

## 범위

### 포함

- 한국어 우선, 영어 확장
- 로컬 음성 녹음
- transcript 편집
- 음량·무음·clipping·길이 검사
- 음성 인식 기반 transcript 일치 후보 판정
- LoRA 기반 개인 adapter 학습
- Voice Package 관리
- 긴 텍스트 chunk 합성

### 제외

- 다중 사용자 서버
- 외부 음성 API 의존
- 자동 음성 복제 공유 마켓
- 무단 음성 사용을 전제로 한 기능

## 품질 원칙

자동 판정은 보조 수단이다. 사용자는 녹음 결과를 직접 재생하고 채택/재녹음을 결정할 수 있어야 한다.
