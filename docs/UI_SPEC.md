# macOS UI 명세서

## 화면

### Dashboard

- Voice 프로젝트 목록
- 학습 상태
- 최근 생성 음성
- MPS/CPU 상태

### Recording

- 권장 문장
- 녹음 시작/중지/재녹음
- waveform과 재생
- transcript 편집
- 품질 점수와 판정 이유
- 다음 문장 버튼

### Dataset Review

- 전체 녹음 목록
- 사용 가능/재녹음/제외 필터
- 음성 및 transcript 비교
- 학습 데이터 확정 버튼

### Training

- 기본/고급 설정
- 진행률, step, train/dev loss
- 중지·취소·resume
- CPU/MPS 사용 표시

### TTS

- Voice 선택
- 텍스트 입력
- 언어 선택
- 생성·재생·저장
- 긴 텍스트 chunk 상태

## 상태 색상

- 초록: 사용 가능/완료
- 노랑: 사용 가능하지만 개선 권장
- 빨강: 재녹음 또는 입력 수정 필요
- 회색: 대기/미검증

## 오류 메시지 원칙

기술 traceback 대신 사용자가 조치할 수 있는 문장으로 표시한다.

예: `MPS를 사용할 수 없어 CPU로 실행합니다. 학습 시간이 길어질 수 있습니다.`

## 접근성

- 키보드로 녹음 시작/중지 가능
- 재생 버튼에 명확한 label
- 색상만으로 판정하지 않음
- 긴 문장과 오류 메시지에 충분한 대비 제공
